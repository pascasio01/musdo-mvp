# MUSDO MVP

MUSDO is a human music platform for composers, demos, lyrics and licensing.

## Core Modules

1. Listener Mode
- Home
- Search
- Music Player
- Library
- Playlists
- Artist Profiles

2. Composer Mode
- Composer Vault
- Upload Lyrics
- Upload Demo Audio
- Song Passport
- Human Verified Badge
- Licensing Marketplace
- Creator Profiles
- Song Analytics

## First MVP Goal

Build Composer Vault first.

A composer can:
- create a profile
- upload lyrics
- upload a demo
- mark a song as private or public
- generate a Song Passport
- receive license requests

An artist can:
- search songs
- listen to previews
- request a license
